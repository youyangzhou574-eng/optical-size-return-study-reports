# Optical Report Index

This folder is reserved for complete reports from OPTICAL_SIZE_RETURN_STUDY.
No report package has been published in the initial repository setup.

Each future report version must have a complete REPORT.md, readable attachment
index, and manifest.json. A report-directory link alone is not enough: the
paired decision conversation should receive a short summary, file list, and
an immutable commit link.

For split CSV datasets, record file order, dataset and column definitions,
frequency/coordinate/Yee-offset meanings when applicable, exact row ranges,
and SHA-256 for every part. Preserve raw complex values and correspondence to
source evidence. Validate a split export without rerunning scientific work.

Keep security redactions separate from numerical transformations. Never publish
credentials or unrelated files, even if they were included in a local archive.

No publication grants new solver authorization or changes scientific STOP gates.
