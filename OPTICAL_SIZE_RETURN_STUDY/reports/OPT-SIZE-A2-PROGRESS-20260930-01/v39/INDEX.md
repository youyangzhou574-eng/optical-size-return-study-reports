# 光学开题交接文件索引

- REPORT.md：完整报告，含旧稿核对、已获结果、卡点、六组集中裁定、开题优先级与执行范围申请。
- REPORT_FOR_PRO.txt：与REPORT.md逐字一致的完整可读正文。
- runtime_snapshot.json：最近已核实的P30运行快照及条件估时，不是实时状态。
- evidence_summary.json：既有平面审计、科学预算、资源估算与轻量筛选范围摘要。
- science_metrics.csv：D3原门槛下的关键误差与PASS/FAIL，非新计算。
- PRO_BUDGET_PLAN.csv：本对话50次Pro规划预算分配，不是平台额度或科学求解预算。
- SHA256SUMS.txt：上述文件的字节SHA256索引。

本轮由用户手动转发，执行端尚未向网页提交，未声称Pro已读或已批准。若文件公开在光学专属仓库，仍需使用固定commit位置；文件发布不等于网页交付。旧数据使用正文给出的v24/v25/v37固定版本，不重传旧raw。
