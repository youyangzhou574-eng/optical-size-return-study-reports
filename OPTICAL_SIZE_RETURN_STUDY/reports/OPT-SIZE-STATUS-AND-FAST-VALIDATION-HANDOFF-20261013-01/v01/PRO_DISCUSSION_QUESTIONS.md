## 需要明确回答的问题

1. 在原三角柱周期几何及 wrapped/halo 表示下，是否有可严格证明的更小平移周期？请给出具体平移向量、最小胞内对象、切边/halo 和相同激励的等价条件。不能直接把全周期窗口裁小或仅以相似图像证明周期等价。
2. 若周期不能缩小，适合 screening 的粗化、各向异性网格和薄膜局部细化是什么？25 nm Fe2O3 / 100 nm ITO 的表示保真边界在哪里？哪些近似允许只比较 R/T/总通量趋势，哪些会改变待研究物理？
3. 仅围绕 500 nm 的源频带与短时代表 pilot 应如何选择，使脉冲、传播和衰减信息仍有意义？请区别窄带、少 DFT 点、短运行和早停的作用，不直接给无实测的分钟/小时承诺。
4. 第一份 pilot 应记录哪些最少目标量和成本证据？希望有实际网格节点/步数、实际 runtime、R/T/Q 与有限时间或局部尾段诊断，再据此判断是否真减负及可比较。不要又默认并列启动四个完整细网格长例。
5. 原两个尺寸同时改变了周期。下一步要验证的是现有“尺寸随周期一起变”的工程趋势，还是固定周期/填充率等条件下的单因素柱宽趋势？如果主张改变对照定义，请明确哪些既有结果不可直接比较。
6. 已在途四个长例可作为后置证据，但不应阻塞快筛。是否有必要继续全部作业、以及要不要停止某些作业，需用户明确决定；不要假定 Codex 有 kill 授权。
