## 三、最主要的减负：少记录真实体积，少传原始buffer，而不是少算Fe

### 1. 运行期保留什么？

只需三类Fe包络：

- **水平薄slab**：平膜、顶帽／孔底；
- **分段侧壁窄矩形包络**：覆盖斜壁，避免一个大bbox把整个柱芯或孔腔全部记录；
- **角部／交汇补区**：包括完整周期边界片。

每个体监视器只记录 **一个500 nm频点、Ex/Ey/Ez、无空间插值、downsample=1、无apodization**。原四功率面也只需500 nm，保留正常原生通量计算，不因关闭体场H而破坏它们。

官方支持选择记录的频率和分量；但原生DFT监视器仍按其实际空间包络分配数据。**矩形内不是Fe的点和重叠buffer一样占运行记录成本。**:chatgpt-content-reference{index="1"}

所以包络设计应最小化：

\[
N_{\rm rec}=\sum_{\text{实际监视器 }m}\sum_\alpha N_{m,\alpha},
\]

这里重叠部分也要计入运行成本；后处理才去重。不能按Fe理想几何体积估DFT，也不能把一个大监视器事后切片说成运行期省内存。

**已有Q70本来就是单频，不能再给它计算一次“十点降到一点”的节省。**新方案的节省来自窄包络、E-only和取消不必要重复记录。

### 2. index不需要native／geometry两份同时保留

**在确认实际采用Staircase的这个新方案中，推荐每个采集包络只保留一份原生component index，加冻结几何／对象优先级记录。**

不再常规配置两套重叠index：

- index数据是静态材料映射，官方说明其在仿真开始时计算，不是随每个时间步积累的场DFT；
- `index_detail`保留各分量真实Yee位置；
- 一般layout的`index preview`会忽略部分高级设置，不能当成同等原生映射。:chatgpt-content-reference{index="2"}

可以使用既有安全路径预导真实静态映射，但必须与实际运行网格对应。**最简单稳妥的是让唯一index对象初始化一次并随结果保存，之后不重复导出另一份“geometry index”。**如果它与冻结几何出现矛盾，查矛盾，不用第二份数据掩盖。

### 3. 可以在服务器就地逐块积分，再只传紧凑结果

**可以，而且这是本轮最值得实施的降本项。**

建议流程：

> 正常完成与保护快照 → 在服务器分析模式中打开该快照 → 按小监视器、按分量读取 → 材料筛选与周期去重 → 累加标量及少量位置分布 → 写独立结果文件 → 只传紧凑数据。

可沿用实际支持的接口：

```text
getdata(monitor_name, "Ex", 1)
getdata(monitor_name, "Ey", 1)
getdata(monitor_name, "Ez", 1)
getresult(index_name, "index_detail")
```

`getdata`可逐数据项读取；`runanalysis`执行的是分析对象脚本。**这都是求解后的分析路径，不是运行中免记录的Fe吸收累计器。**:chatgpt-content-reference{index="3"}

两个实现边界要写死：

**先`getdata`整个大monitor再切片，不是低峰值读取。**为控制分析临时内存，要在采集阶段就采用可管理的小包络，或接受每次至少读入一个monitor分量的成本。

**不得为省文件使用清除子结果／裁剪结果功能，导致唯一原始场丢失。**保护快照保留全部真实采集；分析只生成新文件，不改保存结果、不切回layout、不重新求解。不会通过WinRM把几GB数组或复杂原生对象回传。

### 4. “必要原始证据”怎样保留又不传几GB？

保留两层：

| 层次 | 保存内容 |
|---|---|
| **服务器原始档** | 只读完成FSP、原始monitor数据、源／材料／网格与实际终止信息 |
| **紧凑可复算包** | 全部参与Fe求和的分量复E、全局位置索引、积分权重、Fe材料系数、去重／位置标签；坐标轴与offset单独保存；另附各块计数、权重和、积分和及四功率 |

这里传的是**所有参与求和的Fe支持点**，不是只挑几处样本；无须把窄bbox里所有非Fe buffer再次传回。静态材料ID／mask可用无损压缩，复场不降精度。

## 六、单频激励与小胞：本轮不作为省成本前置

### 窄带激励：技术上可解耦拟合，但不推荐现在同时改

官方支持通过材料的`Specify fit range`将材料拟合范围与源范围解耦；因此窄带源并不必然要求重拟合材料。若以后采用，需固定原350–800 nm拟合设置并核对实际响应；**单独调用一次指定带宽的`getfdtdindex`查询，不等于已冻结求解器实际拟合。**:chatgpt-content-reference{index="5"}

不过本轮不优先切换，原因是：

- 只记录500 nm，已经消除了不需要的体场频点成本；
- 源改窄不自动减少薄膜所需的25 nm／12.5 nm网格；
- 自动背景网格可能随源带宽变化，但这要看实际轴，不能提前承诺降本；
- FDTD即使指定单频仍使用时域脉冲，拉窄脉冲可能增加所需注入及衰减时间，1000 fs不一定更有余量。:chatgpt-content-reference{index="6"}

**因此首对维持原宽带源，只单频记录。**不把窄带拟合、网格重生成和脉冲变更同时塞进最低成本首交。

### 等价小胞：可能节省最大，但当前没有证据，不能顺手缩

只有实际完整材料结构在所有高度满足更小的平移周期、源与边界相容，且孔柱两者均成立，才有等价缩胞基础；原生离散对应和归一化也要说明。周期边界要求结构与场都满足相应周期，不能只看12根外形相似。:chatgpt-content-reference{index="7"}

若面积缩为原来的 \(1/m\)，相同照度下吸收功率和Pin都相应缩放，吸收率才保持对应，**不是将局部结果乘12**。

这条可能很省，但当前未验证、未纳入首选输入，**本次不为了探索它再拖住完整周期的一对G25**。

## 七、唯一后备与何时追加

**后备只有G20成对处理，不默认做半网格平移、额外波长或完整收敛矩阵。**

| 实际情况 | 下一步 |
|---|---|
| **G25求解前发现关键Fe薄层缺失** | 不启动有缺陷G25；孔柱共同转G20并重新看材料表示。首批仍可能只需两次新时域求解 |
| **G25完整覆盖、积分和基本一致性成立** | 先交两个完整离散Fe估计及名义差值；注明“单档、排序敏感性未检查”，不等待G20 |
| **需要进一步声称连续薄膜的可靠排序，或G25几何支持严重依赖落格** | 再说明该具体缺口，决定是否做G20配对；不是为了有数字才先做四例 |
| **积分明显非物理、覆盖缺失或归一化不一致** | 先检查同一保存结果的单位、mask、权重和去重；不立刻重跑producer、不裁零或缩放 |
| **G20也不能合理表示薄膜或实际容量不够** | 明确本路线尚不能认证排序，保留已取得结果；不自动全胞5 nm或换无损问题 |

完成检查只保留与目标直接相关的项目：真实正常保存、全部Fe赋值位置已采集、逐分量坐标与权重正确、周期／重叠不重计、同run Pin只归一一次、结果有限及与总功率无明显矛盾。**正常到1000 fs而未达auto，继续标有限窗口，不自动加时。**
