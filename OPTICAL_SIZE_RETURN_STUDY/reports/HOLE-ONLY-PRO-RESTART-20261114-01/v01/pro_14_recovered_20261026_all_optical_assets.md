## 一、单胞构型设计：把“形状”和“排布”两条线真正展示出来

这一部分不能只放一个三角形示意，然后说“我们做过筛选”。**必须把已有比较对象和结果摆出来。**

| 你框下面的内容 | Codex应整理的素材 | 这些图用来说明什么 |
|---|---|---|
| **几何形状与阵列排布筛选** | **四种形状×两种排布的2×4几何总览**；另外拆出四个单形轮廓、两种排布图及包覆剖面 | 我们分别研究过“单个结构长什么样”和“结构怎样排列”，不是直接选定三角形 |
| **界面面积与光学响应比较** | 八组历史指标的分组柱状图／点图；同形状hex与square的配对比较；界面面积或原 \(G_S\) 指标另图并列 | 形状与排布都会影响响应，同时要看到界面面积、材料载量的变化 |
| **确定三角阵列候选构型** | 同一历史模型族的真实场分布拼图＋定量比较；用一句话总结三角构型的筛选依据 | 支持“为什么把三角形作为后续重点”，不强行说它在所有条件下都最优 |

## 二、几何参数选型：旧尺寸、旧高度和当前对照都保留

这一部分不要因为旧模型不同就扔掉，也不要把它们硬接成一条“最终最优曲线”。**按研究阶段分成几个独立panel，就能既完整又清楚。**

| 素材组 | 具体整理内容 | 建议用途 |
|---|---|---|
| **旧孔结构的尺寸／深度研究** | 已有summary对应的离散点、旧参数示意与原场图；目前明确定位到的四项先完整整理 | 展示早期尺寸探索，不把九点计划清单画成九项完成结果 |
| **旧a=1.5 μm柱高系列** | h=1、3、5、7、9、11、13 μm的原通量与历史材料指标；已有低／中／高柱场图作为配套 | 展示完整的历史高度趋势和当时选点思路 |
| **当前1.5／9与3／9尺寸组** | 两个实际单胞示意、十点谱、500 nm配对点图；旁边可放已有侧壁密度／载量图 | 清楚说明小尺寸整套方案响应更高，同时周期和载量也变化 |
| **当前3／7、3／9、3／13高度组** | 三高度光谱、500 nm离散点、两段单位高度增益 | 展示当前材料族的真实高度收益，不把9 μm画成平台 |
| **尺寸选型判据** | 已有“功能要求—制造可行域—合格件代价”条件图，未知项保持待输入 | 说明如何选，而不是先写3／9最优再找理由 |

这部分建议给你三类可以直接拿来拼的图片：

**参数定义图**：边长 \(a\)、高度 \(h\)、周期、间隙和膜厚。  
**真实结果图**：每个模型族自己的曲线或离散点。  
**选型逻辑图**：光学收益与加工需求如何共同决定选择。

要特别保留两个当前结果，不能为了讲3／9而回避：

> 当前尺寸组：1.5／9的500 nm \(Q_C\) 比3／9高约25.14个百分点。  
> 当前高度组：9→13 μm的500 nm \(Q_C\) 仍提高约3.85个百分点。

这些图足以支持“研究了参数影响，并提出工程选型判据”。**但“加工优选已经验证”这一条目前证据不足，不能靠配图把它变成完成结论。**

## 三、光场调控机制研究：不只整理最新尖角理论，旧机制对照也要找回来

这部分素材其实已经很多，关键是按**整体响应—局部场—干预对照—理论解释**组织，而不是把所有云图堆一起。

| 素材组 | 应交的具体图 | 主要回答的问题 |
|---|---|---|
| **光谱、偏振、角度响应** | 当前X/Y的R、T、\(Q_C\)十点谱；500 nm的0°／30°／60°离散结果 | 结构在不同照明条件下表现怎样 |
| **波长／偏振下的真实场** | X400／650／750 nm，X/Y500 nm的XZ、YZ、XY独立panel；分量图另外存备选 | 光场分布怎样改变 |
| **旧材料与折射率对照** | normal、no-Fe、折射率匹配、lossless-shell等已有结果；配干预结构示意 | 壳层损耗、折射率对比等因素怎样参与响应 |
| **旧轴向／侧向传播线索** | 已保存的 \(P_z(z)\)、径向能流、侧壁吸收分布及原相关图 | 是否存在由柱内部向包覆侧壁耦合的历史线索 |
| **局部尺度与角部统计** | \(w(s)\)几何示意、真实包覆角位置、固定ROI、角／侧均值比与积分代理份额 | 微米主体怎样包含局部尺度，局部集中与整体贡献有什么区别 |
| **独立Maxwell与切割积分** | 尖／圆几何与驱动图、两驱动耗散对比、已有K响应、带符号空间收支和角部定位 | 圆化怎样依赖驱动地改变膜内耗散，变化主要出现在哪里 |
| **S／C／F圆角三组** | 已具备的真实几何、功率、ROI和共同空间场比较 | 区分完整圆化与旧额外裁切；F若尚未交付，不填预测结果 |

**旧no-Fe、折射率匹配、lossless-shell和轴向／侧向能流结果必须纳入整理清单。**不能因为最近一直讨论圆角，就把之前做过的机制工作遗漏了。

不过不同证据保持各自意义：旧no-Fe差值不是原模型Fe吸收，相关图不等于唯一模式；二维理论吸收截面也不等于P30的三维吸收率。用简短图注交代即可，不必让每张图都布满警告。

## 四、怎样保证“每一条都有充分证据”，而不只是文件夹里有几张图？

我给Codex的要求是做一张**九条研究内容—证据—图片对应表**。每一条至少回答：

| 检查项 | 必须交代的内容 |
|---|---|
| **比较对象是什么？** | 形状／排布／尺寸／材料或驱动的明确示意 |
| **结果在哪里？** | 对应真实曲线、离散数据、场图或已完成理论图的编号 |
| **这组证据能说明什么？** | 一句可以直接放PPT里的结论 |
| **哪里不能越界？** | 只写最重要的一句限制 |
| **来源在哪里？** | 原CSV／数组／原图／报告位置，不让你以后找不到 |

**充分性应针对“这句话”判断，不是针对“最终模型所有问题都已证明”判断。**

例如，历史八组数据足以展示形状／排布筛选，但不能直接证明当前P30三角形普遍最优；参数组足以展示尺寸／高度趋势，但尚不能证明制造成本最优。这些都可以成为有用素材，不需要因此停工。

还有一个必须避免的混用：旧开题稿中某些“局部吸收”按层间能流差定义，本来就不同于远场吸收或后来的材料积分。**这些结果可分别使用，不能改成同一个纵轴名称混画。**:chatgpt-content-reference{index="2"}
