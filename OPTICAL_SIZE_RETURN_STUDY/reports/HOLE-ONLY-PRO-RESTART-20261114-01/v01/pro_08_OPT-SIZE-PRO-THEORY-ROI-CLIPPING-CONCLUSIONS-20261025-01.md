## 方程和实现

采用 e^(-i omega t)、各向同性非磁性材料、beta=0。该特例的两个标量未知量是 Maxwell 的精确解耦，不是静电近似：

- Ez：`div(grad Ez) + k0^2 epsilon_r Ez = 0`。
- Hz：`div(epsilon_r^-1 grad Hz) + k0^2 Hz = 0`。

对 scattered field 组装背景对比源；Hz 的右端包含 `-(epsilon^-1-epsilon_b^-1) grad H_bg dot grad test`，不能只复制 Ez 的质量源项。恢复 `H=(i omega mu0)^-1 curl E` 或 `E=i(omega epsilon)^-1 curl H` 后，按实体域积分 `omega epsilon0/2 Im(epsilon_r) |E|^2`，保留材料界面的正确法向不连续。所有复 E/H 六分量均保存，解耦导致某些分量为精确零。

几何用 Gmsh 精确圆弧构造共享材料边界，二次曲几何映射；有限元使用 scikit-fem P2，16 点三角形积分，SciPy 复稀疏直接解。主问题物理半径 3 um、PML 外半径 4 um；径向伸缩 `r'=r+i strength*(r-r0)^3/(3*L^2)`，strength=3，梯度张量 `det(J) J^-1 J^-T` 和质量项 `det(J)` 同时变换。PML 不计入材料吸收，外边界只令散射场为零。

这用可核查 PML 截断替代旧合同定义的形式化精确 DtN；不是声称已经实现精确 DtN。该 PML 半径与原合同示意 Gamma=5 um 不同，数值选择在本次 PLAN 中明确记录，不能将其作为 P30 的出射算子。

| 独立给定的目标 \(F_{\rm req}\) | 三个高度中名义达标的最低代价候选 |
|---|---|
| \(F_{\rm req}\le0.621232\) | H07 |
| \(0.621232<F_{\rm req}\le0.641940\) | H09 |
| \(0.641940<F_{\rm req}\le0.680483\) | H13 |
| \(F_{\rm req}>0.680483\) | 这三个候选均不达标 |

**这张表是需求敏感性图，不是在替用户把需求选进H09的区间。**成本排序和实际可制造性尚未给出时，也不能输出实际赢家。2900 fs的横向尺寸组应另画，不与1000 fs高度组插值成一个伪统一优化面。

UV相关表述目前可写为：

> 该设计将微米级主体图形与薄膜／有限角部形貌所产生的局部光学响应相结合，为降低对整体进一步小型化和更高深宽比加工的依赖提供了设计可能。

尚不能写：

> 普通UV已实现当前200 nm圆角容差，或该路线总成本、良率普遍优于EBL、激光直写及DUV。

当前200 nm是模型参数，不是已测工艺窗口；降低名义尺寸要求也不自动等于整个制程成本或良率改善。

## 可直接写入开题的两条结论

下面两句保留本轮新增证据的正面价值，同时删除“平台／最优”和“普遍尖角增强”的越界解释。

:::writing{variant="document" id="58371" title="3／9选型与三角角部作用的当前结论"}
**3 μm／9 μm选型：**当前同材料尺寸与高度对照表明，减小横向尺寸或将柱高由9 μm增至13 μm仍可提高所计算的控制域净损耗，9 μm尚未呈现明确光学平台，因此3 μm／9 μm应作为结合独立功能要求、当前凸柱制造可靠性及合格样品代价进一步选择的工程候选，而非已证实的光学最优点。

**三角角部作用：**有限膜厚Maxwell截面计算与已有三维场统计共同支持角部形貌具有驱动和观察尺度相关的光场调控作用，但不同驱动、均值及区域积分可呈现不同趋势，且旧圆角三维输入存在额外Fe裁切，故目前不能将局部场集中或旧净损耗差直接解释为尖角对整个阵列Fe₂O₃吸收的普遍增益。
:::

**本轮最重要的推进，是把两个问题分开：FULL负责澄清圆角干预，真实应用和制造数据负责决定3／9是否值得选。两者都不需要通过重跑已完成仿真来维持预设结论。**
